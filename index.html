Selected work

Projects

Robotics research · 2026

Robotic Teleoperation System

A GELLO-style passive leader arm that teleoperates an AgileX NERO 7-DOF robot. Seven joint angles are read straight off the servo bus and mapped to the follower with no inverse kinematics, for scalable imitation-learning data collection. The MuJoCo model was verified joint-for-joint against the manufacturer URDF.

Python · Feetech SDK · MuJoCo · ZMQ · Fusion 360

Private repository — code available on request

UAV autonomy · 2026

AerX Tactical Route Planner

A mission-planning simulator that plans a complete, survivable UAV sortie over real-world elevation data — flying in, hiding from radar in the terrain, and returning home on a single tank of fuel. Uses D* Lite global planning with automatic replanning and an inverse-R⁴ radar model with terrain line-of-sight masking.

Python · D* Lite · RRT* · rasterio · CesiumJS

View on GitHub →

AI & security · 2026

TRINETRA

An autonomous vulnerability detection and repair platform built for the AI Kavach challenge. It combines static analysis, dynamic analysis, and fuzzing to find flaws, reasons about fixes with AI, and proves that exploits fail while functionality stays intact — 32 of 32 end-to-end tests passing across five vulnerability classes.

React · TypeScript · Python · Docker · Gemini

View on GitHub →

Signals & systems · 2026

Audio Fingerprinting System

An interactive audio identifier built with STFT spectrograms, local-maxima detection, and combinatorial hashing. It indexes 5.25 million hashes across 50 songs and stays accurate down to −5 dB signal-to-noise ratio.

Python · Streamlit · Digital signal processing

Robotics · 2026

Gesture-Controlled Robotic Arm

A 6-DOF robotic arm controlled in real time through hand gestures, pairing an in-house 21-part mechanical assembly with computer-vision landmark tracking mapped directly to servo positions.

OpenCV · MediaPipe · Arduino
